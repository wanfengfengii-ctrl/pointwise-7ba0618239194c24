# 望溪合唱团排练谱工作台

声部长导入原谱，团员在浏览器校对各自的声部，指挥审阅拍格、签存并发给团员同一本排练谱。工作稿可以继续修改，已签存的谱仍按原号领取。

## 启动

使用 Python 3.11 标准库。从项目根目录运行 `python3 -B -m score.web.app --db rehearsal.sqlite3 serve`，在浏览器打开 `http://127.0.0.1:8000/`。服务默认监听本机，例谱首次启动时导入。`python3 -B -m score.web.app --db rehearsal.sqlite3 init` 可单独初始化，重复运行返回例谱的当前正式版。使用 `python3 -B -m score.web.app --db rehearsal.sqlite3 import 样例路径.json` 导入不同源谱号的谱，输入结构可参照 `samples/wangxi.json`。

## 一次排练

1. 从工作台打开一份谱，选择声部和小节。原谱中 `bars` 与 `voices` 的数组顺序是谱序。每个逐词条目含 `bar`、`text` 和整数 `beat`。四拍小节允许 `0` 至 `3`。同一个声部小节内按条目顺序登记词。
2. 两名团员分别打开同一小节。替换时在同一表单指定第一词和最后一词，单词替换的两端相同。插入时选择两词之间或小节首尾的缝。词序号用于区分页面上的同字词。草稿按空白分词，空替换表示删除。
3. 若乙把 Y 插在 B 与 C 中间，甲旧页的 B C → X 会显示冲突、当前词和草稿 X。甲可以在现谱重新选择。如果乙把 Y 插在 C 后，甲可直接保存 A X Y。
4. 保存页显示实际保存的版本。打开预览时选择首尾小节，系统按谱序取包含两端的范围。一个拍格对应一拍，页上拍号从 1 显示。同拍多词保持词序，休止拍在进唱紧邻之前才显示换气。
5. 在预览页签存，再将定稿号码或页面地址交给团员。工作台的定稿目录也能进入该页。签存之后可继续改稿，原定稿保留当时的版本、范围、拍格和提示。

新替换词落在段首词原拍。插入词取左邻拍，无左邻时取右邻拍，空小节取零拍。空插入没有写入。冲突整笔拒绝，只有实际成功的编辑才产生正式版。找不到版本、小节或定稿时返回 404，非法输入返回 400，存储写入失败返回 503。网页中的词和草稿以文字呈现。

## HTTP 入口

- `GET /worksheet?revision=1&voice=sop&bar=1` 打开指定工作版。也可用 `score=wangxi` 代替 `revision` 以打开当前版。
- `POST /edit` 使用编辑页发出的 URL 编码表单。保存返回 200 和实稿页面，冲突返回 409 和可继续编辑的现谱页面。
  - `kind=replace`：普通替换，字段 `first`、`last`、`draft`，空草稿表示删除。
  - `kind=insert`：缝中插词，字段 `gap`、`draft`。
  - `kind=resegment`：重分词，字段 `first`、`last` 为当前工作版上一段连续同拍词，`draft` 按空白分词；拼接后逐 Unicode 码点必须与原段相同，字符身份和拍位照留，只受理当前工作版。
  - `kind=liaison`：标注连读，字段 `gap=[原版号, 左原词号, 右原词号]`；两原字以原顺序仍相邻即可办理，已在同一词内也可，办理后附着于实际保存版。
- `GET /preview?revision=1&first=1&last=2` 按指定工作版和范围审阅，列出各连读标记在该版的可见、暂隐或失效状态，并在实际词缝标出可见项。
- `POST /edition` 接收预览页给出的 `revision`、`first`、`last`，成功返回 201 和定稿地址；只把所审范围内可见的连读提示连同拍格、换气写入成品。
- `GET /edition?number=1` 领取定稿。

### 连读标记的生命周期

标记记录的是两个原字符身份之间的缝，而非词文。两原字仍在正式词序相邻且处在实际词界时可见；并入同一词或被插词隔开时暂隐，词界恢复后复显；任一原字被普通改词删换后在后续版本永久失效。普通改词写入的新字即使同字同拍也取得新身份，不能承接原标记。

## 正常回归

`python3 -B check_project.py`

平台的回归入口执行 `tests` 包中的完整 unittest。测试从真实 HTML 取表单，使用临时 SQLite 库和本机 HTTP 服务。`python3 -B -m tests.support` 演示从原页改词到重开后领取定稿的链路，并打印观察到的词序、拍格和定稿出处。
